# COMP3008-A4-Group-2
Implementation of the following figma prototype: https://www.figma.com/design/mDc9f44L98GCDrqElz8VjG/COMP3008-Assignment-3-Design?node-id=0-1&t=Rdjtj5oEINvg89yD-1

## Requirements
- A modern web browser.
- No additional dependencies or external APIs are required.
- Office information and wait times use local demonstration data.

## Run instructions
1. Extract the submitted source ZIP.
2. Open src/index.html in a web browser.
3. Select "Passport & Biometrics", "2-9 Business Days",
   and "Ottawa" to begin the selected task.
4. Review the results and click an office name.

Alternatively:
- Run the following in a terminal: `git clone https://github.com/MatthewBFewer/COMP3008-A4-Group-2.git`
- Open your web browser and press `ctrl + O`
- navigate to the folder `COMP3008-A4-Group-2` and select `src/index.html` as the file to open
- Select "Passport & Biometrics", "2-9 Business Days",
   and "Ottawa" to begin the selected task.
- Review the results and click an office name.
